Website Practice Desk (internal)
I · Voice

We write like a good senior associate: precise, unhurried, no adjectives doing the work of facts. We say “the conflicts search took four seconds”, not “lightning-fast intelligent conflict resolution”.

II · Restraint

Oxblood is the house colour and appears once per view. Brass marks things that are waiting on a person. Everything else is ink on paper.

III · Agents keep a file

Every agent we build records what it read, what it did and which rule decided. Professional judgements, like clearing a conflict, are always held for a named person.
