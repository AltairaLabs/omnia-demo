# Sizing Guide

Acme Apparel sizing is consistent with standard US sizing with a few category-specific notes. If you're between sizes or coming from another brand, read the relevant section below.

## How our sizing runs

| Category | Fit |
|---|---|
| **Tops (shirts, blouses, tees)** | True to size |
| **Dresses** | True to size |
| **Bottoms (pants, trousers, skirts)** | True to size |
| **Denim** | Runs slightly small — if you're between sizes, go up one |
| **Outerwear (jackets, coats)** | Runs generous — if you're between sizes, go down one |
| **Sweaters (wool, cashmere)** | True to size, but allow for possible 1-3% shrinkage after first wash |
| **Shoes** | True to size; half sizes available in most styles |
| **Accessories** | One size unless noted |

## If you're used to other brands

Acme sizing is most similar to brands like Everlane, Quince, and Cuyana. If you usually wear a medium in those brands, you'll fit comfortably in our medium. If you normally shop at brands that run large (most fast fashion), our medium might feel snugger — consider sizing up one.

## Between sizes?

For tops and dresses, default to the **smaller** size if you prefer a fitted silhouette or the **larger** size if you prefer a relaxed fit.

For denim, go up if you're between sizes — Acme denim tends to break in slightly and loosen, not tighten.

For outerwear, go down if you're between sizes.

## If you order the wrong size

We'll **exchange it for free**. Just contact support within 30 days, we'll send you a prepaid return label, and the correct size will ship as soon as we receive the original. No fees, no hassle — we'd rather you end up with something that fits. See `returns-and-exchanges.md` for the full exchange process.

## How to measure yourself

You need a soft measuring tape (the fabric kind, not a metal contractor's tape) and ideally someone to help. Measure over light clothing, not a bulky sweater.

- **Bust / chest**: around the fullest part, keeping the tape parallel to the floor
- **Waist**: around the narrowest part of your torso, usually about an inch above your belly button
- **Hip**: around the widest part of your hips, usually 7-9 inches below your waist
- **Neck**: around the base of your neck, with one finger between the tape and your skin for comfort

If your measurements fall between two sizes on the chart, use the "between sizes" guidance above.
