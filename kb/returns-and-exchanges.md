# Returns and Exchanges

We want you to love what you buy. If something isn't right, here's how to return or exchange it.

## Return window

You have **30 days from the delivery date** to return an item. We use the carrier's delivery confirmation as the start of the clock. After 30 days, items are no longer returnable (except for defective or damaged items — see below).

## Return conditions

Items must be returned in **original condition with tags attached**. That means:

- Unworn and unwashed
- Tags still attached to the garment
- Original packaging when possible (not required but appreciated)
- No pet hair, perfume, smoke smell, or other wear indicators

We inspect every return. If an item comes back worn, washed, or damaged, we'll either refund you minus a restocking fee or ship the item back to you at our discretion.

## What's NOT returnable

- **Sale items** — anything marked "Final Sale" on the product page is not returnable or exchangeable. This is the #1 thing customers are surprised by; we flag it clearly at checkout but please double-check before buying sale items.
- **Swimwear and intimates** — for hygiene reasons, these are final sale.
- **Gift cards** — not returnable, not refundable, but also don't expire.
- **Worn items** — see "return conditions" above.

## Refund method and timing

Refunds go back to the original payment method. Processing times:

- **From the day we receive your return**: 1-2 business days for us to inspect and approve
- **After approval**: 5-7 business days for the refund to appear on your statement (varies by card issuer)

Total round-trip is typically 2-3 weeks from when you ship the return to when the refund hits your account.

## Exchanges

Exchanges are **free** and the new item ships as soon as we receive the original. If you want to exchange for a different size or color of the same item, there's no additional cost (even if the sizing goes up a price bracket — we eat that).

If you want to exchange for a completely different item, it needs to be the same price or less. For anything more expensive, we'll refund the original and ask you to place a new order.

## How to start a return

1. Reply to your order confirmation email or contact support
2. Tell us which item(s) you're returning and why
3. We'll email you a **prepaid return label** within one business day
4. Drop the package at any USPS location (or schedule a pickup)

You can also return via any FedEx or UPS store if you prefer, but you'll need to cover the return shipping cost yourself (we only prepay for USPS).

## Defective or damaged items

**Different rules apply.** If an item arrives damaged, defective, or incorrect, you get:

- Full refund OR free replacement (your choice)
- **We pay return shipping**
- No restocking fee
- Return window is 60 days, not 30, for defective items

See `damaged-or-incorrect-items.md` for the exact process.

## International returns

International customers pay their own return shipping unless the item is defective. Beyond that, the same 30-day window and same return conditions apply. Duties paid at import are **not refundable by us** — you'll need to contact your local customs authority for a duty refund.
